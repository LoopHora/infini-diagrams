# Feature Stress Matrix

For every valid fixture test applicable combinations of:

## Source
- minimal
- comments
- blank lines
- long source
- long labels
- Unicode
- Malayalam
- Hindi
- CJK
- emoji
- quoted labels
- URLs where supported
- styles/classDef where supported
- frontmatter
- directives
- diagram-specific config

## Layout/look
Where supported:
- default
- ELK
- Dagre
- classic
- neo
- handDrawn

## Themes
- default
- dark
- forest
- neutral
- custom theme variables where product exposes them

## Background
- transparent
- white
- black
- custom color

## Viewer
- 25%
- 50%
- 100%
- 200%
- fit
- reset
- pan
- fullscreen
- very wide
- very tall
- dense

## Export
- SVG
- PNG 1x
- PNG high scale
- PDF
- MMD
- clipboard where supported

Never export a screenshot of the visible viewport as the normal diagram export.

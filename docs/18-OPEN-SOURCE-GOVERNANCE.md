# Open Source Governance

The product is intended to be open source.

## Before release

Prepare:
- LICENSE;
- README;
- CONTRIBUTING;
- CODE_OF_CONDUCT;
- SECURITY;
- issue templates;
- pull-request template;
- dependency/license inventory.

## Dependency policy

Record:
- Mermaid version;
- export libraries;
- PDF library;
- rasterization libraries;
- editor library;
- font licenses.

Do not copy code or assets without compatible licensing.

## Security reporting

Provide a security-reporting mechanism appropriate to the repository.

Do not publish exploit details for an unresolved vulnerability in an irresponsible manner.

## Reproducible development

Document:
- install;
- dev;
- test;
- build;
- preview production;
- lint;
- typecheck.

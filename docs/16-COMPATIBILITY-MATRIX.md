# Compatibility Matrix

## Mermaid compatibility

Maintain a checked matrix for every Mermaid diagram type supported by the pinned Mermaid version.

Columns:
- diagram type;
- minimal example;
- theme;
- dark background;
- transparent background;
- SVG;
- PNG;
- PDF;
- mobile;
- invalid input;
- notes.

## Browser compatibility

Track:
- Chrome/Chromium;
- Safari/WebKit;
- Firefox;
- iOS Safari;
- Android Chrome.

## Feature states

Each capability must be:
- Supported;
- Supported with limitation;
- Unsupported and hidden;
- Unsupported and clearly explained.

Never silently pretend support.

## Dependency updates

Every Mermaid version upgrade requires:
- compatibility matrix rerun;
- security review;
- export regression suite;
- bundle-size check;
- browser regression;
- release note.

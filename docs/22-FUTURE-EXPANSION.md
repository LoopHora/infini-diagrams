# Future Expansion

This document contains genuine future expansion, not missing V1 functionality.

Possible future diagram engines:
- PlantUML;
- Graphviz/DOT;
- additional text-to-diagram languages.

Potential future capabilities:
- batch conversion of many source files;
- Markdown document processing;
- repository-aware documentation workflows;
- integrations;
- optional collaboration;
- optional shareable links;
- optional AI assistance.

These must not weaken the V1 local-first architecture.

The engine/export registry architecture exists so new diagram languages can be added without rewriting the product.
